Fundamento Esencial

¿Por qué estos conceptos son la base de React?

En el video, Fazt explica que React no inventa una sintaxis rara aparte de JSX: React es JavaScript puro con programación funcional. Si dominas las funciones flecha, el destructuring, los métodos inmutables (.map, .filter) y la asincronía, aprender React es pan comido.

1. Funciones & Arrow Functions

Funciones que retornan funciones y retorno implícito

03:42

Fazt muestra cómo una función puede devolver otra función y cómo las Arrow Functions permiten escribir componentes y cálculos concisos: 

// Arrow function con retorno implícito
const add = (x = 0, y = 0) => x + y;

// Función que retorna otra función (base de HOC / Currying)
function buildGreeting(greet) {
  return (name) => `${greet}, ${name}!`;
}
